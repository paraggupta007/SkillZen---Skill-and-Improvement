# Viva questions and answers (in progress)

1. **What is SkillZen?** A planned interview and mock-test practice platform with feedback.
2. **What is a monorepo?** One repository holds the API and web applications.
3. **Why TypeScript strict mode?** It catches many type errors before the app runs.
4. **What is Drizzle?** A TypeScript ORM and migration toolkit for SQL databases.
5. **Why a pooled Neon connection?** It helps control database connection usage.
6. **What is a repository?** A data-access abstraction that keeps persistence details away from services; it is planned.
7. **What is an event bus?** A publisher notifies subscribed handlers without directly depending on them.
8. **What does the health endpoint test?** Whether the API process can respond, not database readiness.
9. **Why avoid uploading webcam video?** Local processing reduces sensitive data exposure.
10. **Can webcam gaze prove cheating?** No. It is an imperfect coaching estimate affected by lighting, camera position, disability and other factors.

The full set of 40+ questions will be written as the modules are implemented.
